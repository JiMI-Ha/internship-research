# Privacy, Copyright, and Source Policy

## 公开内容原则

本站发布的是原创的结构化阅读笔记、研究判断、链接与引用信息，不是论文全文镜像或私人资料仓库。

- 只链接到公开的 DOI、arXiv、会议页、出版社页、作者公开稿或公开代码仓库。
- 不提交受版权保护的原始 PDF、付费下载内容、网页抓取副本或临时转换文件，除非拥有明确再分发权。
- 论文中的图、表、长段落和补充材料不应直接复制；需要引用时使用必要的短引文并标明来源。
- 数字、实验结论与方法描述应能追溯到公开来源；不因“看起来合理”而补写。

## 隐私与敏感信息

提交前检查并移除：

- API key、Token、Cookie、SSH key、账户信息；
- 内网 URL、非公开文档链接、客户数据、未发布项目名称；
- 本地绝对路径、个人邮箱、机器用户名和聊天记录；
- 未经同意的个人信息、访谈原始数据或截图；
- 不适合公开的业务策略、评审意见或合作方材料。

不要把原始本地 PDF、浏览器缓存、构建产物或临时下载目录提交到 Git。

## AI 辅助研究的要求

AI 可以帮助检索、整理、标注候选机制和起草笔记，但不能成为来源本身。

1. 关键结论必须回到原文或可靠公开来源核对。
2. 无法获取全文时，明确记录证据限制，并避免伪造实验设置、数字、消融或因果解释。
3. 对 `unknown`、未报告和证据冲突保持可见，不用自动分数掩盖不确定性。
4. 编辑判断、Lens 配置与个人排序需标为当前项目下的判断，而不是事实陈述。

## 开源贡献

提交 Pull Request 即表示贡献者确认：

- 其提交内容有权按仓库许可证发布；
- 没有包含机密、个人敏感信息或侵权材料；
- 引用和来源链接尽可能准确；
- 可以接受维护者为准确性、隐私、版权和格式进行修改或拒绝。
